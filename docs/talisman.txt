Elixir Script for Dataset Generation


Here’s an Elixir script to spit out your 6-month, 10-minute interval BTC-ish dataset with price and volume, ready for E-TPV sims. It’s flexible—adjust dates, noise, events, or scale.

defmodule BTCDataGenerator do
  @doc """
  Generates a synthetic BTC price dataset with volume for E-TPV analysis.
  - Start: Aug 25, 2024, 00:00 PST
  - End: Feb 24, 2025, 23:50 PST
  - Interval: 10 minutes (26,208 rows)
  - Price: $62K start, $90K end, noise + events
  - Volume: 5-500 BTC, low during "failures"
  """
  def generate_dataset do
    start_date = ~U[2024-08-25 00:00:00Z] # UTC, adjust to PST in output
    end_date = ~U[2025-02-24 23:50:00Z]
    interval_minutes = 10

    # Total data points
    total_points = div(DateTime.diff(end_date, start_date, :second), 60 * interval_minutes)

    # Base price trend: $62K to $90K over 6 months
    price_start = 62_000.0
    price_end = 90_000.0
    price_step = (price_end - price_start) / total_points


    # Event spikes: mimic real drops (e.g., 7% Feb 24, FTX-style low-vol crash)
    events = [
      {~U[2024-11-15 12:00:00Z], -0.10, 20}, # 10% drop, low vol (failure sim)
      {~U[2025-01-20 08:00:00Z], -0.05, 100}, # Inauguration dip, 5%
      {~U[2025-02-24 14:00:00Z], -0.07, 150}  # 7% today, high vol
    ]


    # Generate
    File.write!("btc_data.csv", "Timestamp,PBTC,Volume\n")
    Enum.reduce(0..total_points-1, price_start, fn i, price ->
      timestamp = DateTime.add(start_date, i * interval_minutes, :minute)
      # PST offset (-8 from UTC)
      timestamp_pst = DateTime.add(timestamp, -8, :hour)

      # Noise: 0.2-2% jitter
      noise = :rand.uniform() * 0.018 - 0.009 # -0.9% to +0.9%
      trend_price = price_start + (i * price_step)
      new_price = trend_price * (1 + noise)

      # Apply event spikes
      event_adjust = Enum.find_value(events, 0, fn {date, drop, _vol} ->
        if DateTime.compare(timestamp, date) == :eq, do: drop, else: 0
      end)
      adjusted_price = new_price * (1 + event_adjust)

      # Volume: 50-500 BTC normal, drops to 5-20 on "failure" events
      volume = case Enum.find(events, fn {date, _, _} -> DateTime.compare(timestamp, date) == :eq end) do
        {_, -0.10, low_vol} -> low_vol + :rand.uniform(15) # Low vol failure
        {_, _, _} -> 50 + :rand.uniform(450) # Normal/high vol
        nil -> 50 + :rand.uniform(450)
      end

      # Write to CSV
      line = "#{timestamp_pst},#{Float.round(adjusted_price, 2)},#{volume}"
      File.write!("btc_data.csv", "#{line}\n", [:append])

      # Next price starts from adjusted
      adjusted_price
    end)
    IO.puts("Generated btc_data.csv with #{total_points} rows")
  end
end

# Run it
BTCDataGenerator.generate_dataset()

Tweaks


Smaller: Cut total_points—e.g., 1 month = ~4,320 rows (end_date = ~U[2024-09-24 23:50:00Z]).

Different: Adjust price_start, price_end, events, or noise range (e.g., 0.05-5%).

Failures: 10% drop’s your FTX proxy—add more (e.g., 20% Dec 1) or yank if too fake.

Enhanced Total Percentage Variation (E-TPV):

Measures volatility via swings between local maxima/minima, thresholded for significance, weighted by volume, and normalized by mean swing time. Splits high/low volume for LTP insight.


Inputs:
PtPt​: Price at time tt (e.g., 10-min intervals).

VtVt​: Volume at time tt (e.g., BTC traded).


Steps:

Calculations:
High Volume: E-TPV=∑Si⋅ViTˉE-TPV=∑TˉSi​⋅Vi​​ (volatility weighted by volume, per mean time).

Low Volume: E-TPVlow=∑SiTˉE-TPVlow​=∑TˉSi​​ (unweighted, LTP/illiquidity flag)—reported separate.


Output: Dual metrics—E-TPV (main), E-TPV_low (LTP watch)—tunable thresholds.

Purpose: Noise-free volatility (delta), LTP-aware (low vol), front-running safe (volume split)—$6.5K-$8K hunt-ready.


Simulated Failures: Yea or Nay?


Pros:


Tests survivorship—FTX ’22 (80%, low vol), Lehman ’08 (freeze)—did E-TPV_low spike pre-bust?

LTP flags—low-vol crashes signal tar pits, your “dreaded” foe.

Behavioral hints—crowd panic vs. live calm.

Cons:


Overfitting—fake failures (10% Nov 15) might skew to script, not reality.

Too synthetic—real failures (FTX) have nuance (news, halts) sims miss.

Verdict: Include 1-2 (e.g., Nov 15’s 10%, low vol)—plausible, not wild. Cross-check real failures (FTX ’22 via CryptoQuant, $50/month)—keeps it grounded. Your call—strip ’em if too “voodoo.”
